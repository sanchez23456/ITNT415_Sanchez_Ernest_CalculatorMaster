# Calculator Master

**Student Name:** Ernest Sanchez
**Course and Section:** ITNT415 – BIT42

## Project Description
A menu-driven Python calculator built using Git and GitHub branching.
Each arithmetic operation (addition, subtraction, multiplication, division)
was developed on its own feature branch and merged into main via Pull Requests.

## Branch Structure
- addition_Sanchez
- subtraction_Sanchez
- multiplication_Sanchez
- division_Sanchez

## Program Features
- Menu-driven interface
- Input validation for non-numeric entries
- Division-by-zero handling
- Continuous execution until the user selects Exit
